# Charismak Accounting

Cloud-first construction accounting, cost-control, treasury and company-finance platform.

## Current stage

Foundation / role-based UI prototype.

Core product principle: **Track the truth.**

The product uses one shared system with four primary interface families:

- MD / Owner
- Accountant / CFO
- Project Director
- Project / Construction Manager

Sub-positions inherit the interface family of the relevant major position, while permissions determine actual access.

## Development

This repository is private. The web application is designed for Vercel preview/staging deployment during development.

Real financial records are not connected in the current UI prototype.
