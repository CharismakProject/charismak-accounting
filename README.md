# Charismak Construction Accounting

Construction-focused accounting and document intelligence for project funding, costs, approvals, statements, reports, and evidence.

## Release intake

The production intake supports Excel (XLSX/XLS), Word (DOCX), PDF including scanned PDF OCR fallback, and JPG/JPEG images. Exact document duplicates are checked using a server-side SHA-256 hash before analysis, and statement transaction fingerprints include value date and running balance to reduce duplicate-posting errors.
